# numhop — ten worlds

## Objective
Add five more worlds after Starry Night, so a match runs through ten.

## Why
The user asked for ten worlds instead of five.

## Scope
- src/domain/levels.rs: five new maps and palettes (Coral Coast, Autumn Woods,
  Misty Marsh, Volcano Valley, Rainbow Heights), each longer and harder than the
  last; a `floor` colour in `Palette` for the backdrop valley.
- src/game/level.rs: the backdrop floor uses the world's palette (the first five
  keep their current colours).
- src/i18n/{en,es,mod}.rs: ten world names.
- Tests that assume five worlds; README mentions of five worlds.

## Constraints
- Maps use only pieces the existing worlds already use (crystal, BCB, CBBC,
  BCBCB, low blocks, mounds, 2–3 tile gaps, the end staircase), so every jump
  height is already proven. Generated by a script so columns line up.
- Level tests must hold: ≥5 crystals, a checkpoint, spawns on ground, gaps ≤3,
  key before gate.
- `Match::tier` is unchanged, but it divides progress by the number of worlds, so
  with ten the ramp from ★ to ★★★★ is slower per world; the last world is still
  the hardest. Pinned by with_ten_worlds_the_stars_climb_across_all_of_them.
- TDD off; runner bin/test. Never run cargo fmt.

- The menu offers up to ten start worlds (as unlocked); clearing world 5 leads
  to Coral Coast and clearing world 10 ends the match.
- Each new world has its own sky, fog, light and floor colour.
- Tests and clippy pass.
